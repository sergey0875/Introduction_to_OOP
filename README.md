## Создан класс Product
со следующими свойствами:
название (name), описание (description), цена (price), количество в наличии (quantity).
Реализован класс-метод 
new_product() с помощью декоратора 
@classmethod . Метод new_product()принимает на вход два аргумента — cls
и продукт для создания в виде словаря — и возвращает экземпляр класса Product на основе данных словаря.


## Создан класс Category
Для класса Category определены следующие свойства:
название (name), описание (description), список товаров категории (products).
Реализован геттер для приватного атрибута products с использованием декоратора @property .
Геттер возвращает строку со всеми продуктами в приватном атрибуте products . Имя метода-геттера — products .
Каждый продукт в геттере сформирован как строка строго по шаблону: 
"Название продукта, X руб. Остаток: X шт.\n"



## Создан модуль utils
для чтения json файла и инициализации объектов Category и Product из списка словарей.
